# ADR 0007: Religia poza zakresem wersji podstawowej

**Status:** przyjęta, 2026-11-03

## Kontekst

Religia to rozbudowany system (wiara, misjonarze, schizmy), który wpływałby na wiele innych.

## Decyzja

Usuwamy religię z projektu. Wróci kiedyś jako osobny moduł.

## Rozważane alternatywy

Religia jako cecha kultury: odłożone razem z modułem.

## Konsekwencje

Teokrację zastąpiła oligarchia, technologię „Wierzenia” zastąpiły „Tradycje”. Kod nie może zakładać istnienia religii.
